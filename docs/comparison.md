# 与 Aerial 的功能对照

参考 [Aerial TV](https://github.com/pengchujin/aerial-tv/tree/f57e46b1b0459b1ced68025538bb85abab955636) 在 2026-10-27 的源码。比较的是当前源码能力；不同设备上的安装、开机和视频表现需要分别验证。

## 桌面与内容

| 能力 | Banana TV 当前情况 |
| --- | --- |
| 应用网格、Dock、排序、隐藏、卸载入口 | 已有。 |
| 文件夹、应用改名 | 已补充图标网格；支持遥控器打开、整理与应用菜单。 |
| 手机拖拽整理、改名、隐藏、文件夹 | 已补充，复用同一份电视布局配置。 |
| 手机上传照片与图标 | 已有。 |
| 信号源固定、改名、设备外观 | 已补充设备外观与改名；实际 HDMI 音视频按设备验收。 |
| 日夜主题、焦点样式、名称和时钟布局 | 已有；补充小号时钟左右位置、主屏幕轻提示音与可选农历日期。 |
| 第二排预览 | Dock 布局下可独立开关；五列网格不受此设置影响。 |
| 双排常用应用首页 | 已补充可选的常用双排布局，每排四个入口，使用独立的轻薄排面板。 |
| 自动／完整／流畅效果、隐藏 Dock 底板 | 已补充。 |
| 114 段航拍与时间字幕 | 已有目录；新增画质选择与失败回退。 |
| 航拍 4K / Dolby Vision 自动选择 | 已补充能力检查，尚未完成实机输出验证。 |
| 照片、时钟屏保、屏保时钟叠加 | 已有并补充叠加选项。 |
| 开机打开 HDMI 或指定应用 | 已有并补充应用选择；当前设备还需要单独做开机测试。 |
| 应用内更新与镜像 | 已有。 |
| 设置 PIN | 数字和方向键 PIN，沿用同一份加盐哈希与失败限速。 |
| 自有影视、最近播放、直播、跨源搜索 | Banana TV 额外提供，订阅由用户配置。 |

## Android 9+ 剩余工作

本轮对照中确认的通用界面功能已有实现，剩余四组适配、验证和分发工作：

| 工作 | 当前状态 |
| --- | --- |
| 系统与设备适配 | 开机、待机恢复、Home、HDMI、亮度及米家／小爱／投屏等关联功能需要按固件验证，发现问题后适配。 |
| 性能与长期稳定性 | 已有局部模拟器验证；仍需实机检查首帧、连续 Home、滚动和长期运行，不能把 60 Hz 请求等同于稳定 60 fps。 |
| 高清航拍输出 | 画质选择和失败回退已有实现，4K／HDR／Dolby Vision 仍待对应设备验证。 |
| 正式分发 | 文档站已有本地版本，公开上线和国内 APK 更新镜像尚待完成。 |

## 本轮不做

- Android 5–8 和 Android 4.x Lite 版后续适配，当前最低 Android 9。
- 按产品选择，不新增主屏幕视频壁纸、持续航拍背景或本地视频上传；可选航拍屏保保留。

功能参考不要求复制界面。Banana TV 的视觉方向见 [功能与使用](features.md#界面方向)。
