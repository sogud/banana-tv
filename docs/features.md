# 功能与使用

本页描述当前源码。GitHub 旧版 v0.1.11 下载与当前开发版并不相同。

下方为开发版在 Android TV 模拟器中的实际截图，分辨率为 1920 × 1080；应用列表取决于设备上安装的应用。

## 主屏幕

- 极简 Dock、常用双排和五列网格三种布局，支持大小、名称和焦点样式调整；Dock 可预览下一排应用，小号时钟可选左上或右上。
- 长按 OK 或按菜单键移动应用、重命名、隐藏、查看应用信息与请求卸载。
- 文件夹分组：创建、改名、添加或移出应用、解散文件夹。文件夹内为图标网格，方向键移动，OK 启动应用；长按 OK 或按菜单键可改名、移动、隐藏或打开系统应用管理。
- 固定 HDMI 等信号源，设置名称和设备外观。设备图案为本地绘制的通用轮廓。
- 可选开机打开应用或 HDMI、数字／方向键设置 PIN。
- 默认 Home 与可选兼容服务。[按设备验证](install.md)。

在 **设置 → 外观 → 首页布局** 选择常用双排，首页最多显示两排、每排四个入口，应用、文件夹和固定信号源共用原有排序。两排之间移动时保持首页位置，第三排起滚动浏览。入口不超过四个时自动按单排显示；同时开启大时钟时，图标会按剩余空间缩小。手机配置页也可切换布局。

## 手机整理

打开控制中心中的 **手机配置**，用同一局域网的手机扫码：

- 拖动磁贴手柄排序，或在编辑面板中向前／向后移动。
- 改名、隐藏／显示应用、创建文件夹、把应用移入文件夹。
- 上传自定图标、图片壁纸，调整部分外观和天气设置。
- 固定信号源、修改信号源名称与设备类型。

会话十分钟到期。关闭电视上的窗口后服务停止。设置 PIN 仍适用；配置页不会绕过锁定。

## 影视与直播

影视首页默认显示 **最近播放**，支持原位置续播、统一分类、跨源搜索、选集、换线、音轨、字幕和画面比例。直播与影视共用播放器，支持多订阅、节目单、分省分组、频道收藏和备用线路检测。

播放失败会提示选择其他来源。连接检测与实际解码不同，频道数量也不代表可播放数量。详见 [影视与直播](media-center.md)。

## 壁纸与屏保

支持本地图片、上传壁纸、原生渐变、可选每日图片和应用配色。内置航拍目录共 114 段，在线串流并带时间字幕；照片轮播和时钟可离线使用。

选择静态图片：**控制中心 → 设置 → 壁纸**，在图库中选中缩略图并按 OK；选中后返回首页。风景和插画均为静态图片，不运行视频解码器。图库的 **4K** 标识指原始图片尺寸，实际显示分辨率由设备与系统决定。

上传自己的图片：选择图库顶部的 **上传壁纸**，手机与电视连接同一局域网，扫码后上传 JPG、PNG 或 WebP；每张最多 20 MB，上传后自动应用。个人图片保存在电视本机，不进入项目源码或文档截图。

## 外观与流畅模式

日间、夜间与跟随系统主题；主屏幕声音可选电视系统、轻提示音或关闭，大时钟可显示农历日期。界面效果可选：

| 模式 | 行为 |
| --- | --- |
| 自动 | 低内存设备使用简化效果，其余使用完整效果。 |
| 完整 | 保留 Dock 材质、图标高光、视差与阴影。 |
| 流畅 | 简化 Dock 材质，关闭图标高光、视差与阴影；保留基本焦点反馈。 |

窗口目标刷新率为 60 Hz。效果模式不是稳定 60 fps 的保证，实际表现取决于硬件、背景与场景。

## 界面方向

后续界面统一使用 Banana TV 自己的设计语言，参考遥控器交互经验，不逐像素复刻其他桌面：

- 主屏幕保留壁纸与常用入口，最近播放位于影视第一屏。桌面、影视、直播与设置共用一致的面板、间距和操作方式，电视设置保持浅入口。
- 以暖白、炭灰为基础，适量吸收壁纸颜色；香蕉黄只用于选中、进度等少量重点。
- 功能图标使用清楚的播放、直播、应用等符号；香蕉作为品牌标识，不替代每个功能的图标。
- 面板边缘轻薄，减少厚重底板与阴影。焦点采用清晰描边和轻微缩放，动效短而克制，返回保留操作位置。

## 更新与隐私

应用更新支持自定 HTTPS 地址、镜像、摘要和签名检查，最后由 Android 安装界面确认。无账号和分析 SDK。订阅、图片和布局保存在电视本机；在线天气、每日图片和航拍按需访问各自服务。
